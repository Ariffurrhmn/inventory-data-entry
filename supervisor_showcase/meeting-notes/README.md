# Meeting notes

The showcase's **Save meeting notes** button (step 6) writes one pair of files here per save:

- `YYYY-MM-DD_HHMMSS.md`: readable summary of the decisions and feedback
- `YYYY-MM-DD_HHMMSS.json`: the same, as structured data

These record the supervisor's direction. They are not training data or ground truth. After a meeting, copy any decision that changes project scope into `Context/DECISIONS.md`.
