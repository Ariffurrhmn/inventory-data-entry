# Shared project context

Read Context/README.md, Context/PROJECT.md, and Context/STATUS.md before starting work. Context/ is the common source of project memory for both Codex and Claude; do not keep separate copies of project facts in assistant-specific folders.

Use Context/ORGANIZATION.md to decide where new files belong. Update Context/STATUS.md after meaningful work and record consequential scope/design decisions in Context/DECISIONS.md. Distinguish verified file contents, historical notes, and unimplemented plans. Never present synthetic records or hand-built examples as measured results.

Preserve raw datasets, ground truth, review history, signed documents, and older deliverables. Do not regenerate datasets or bridge prompts merely to inspect them: generators can overwrite files. Check references before moving assets.
